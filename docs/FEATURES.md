# Feature survey

What today's major browsers offer, and where Drift stands. ✅ in Drift · 🔜 planned · ➖ not planned (reason given).

Browsers surveyed: Chrome, Edge, Firefox, Brave, Arc, Vivaldi, Opera, Safari, Zen.

| Feature | Seen in | Drift |
|---|---|---|
| Vertical tabs | Zen, Arc, Edge, Firefox, Brave, Vivaldi | ✅ |
| Horizontal tabs | all | ✅ (Chrome, Firefox and Brave styles) |
| Pinned tabs / Essentials | Zen, Arc, all | ✅ |
| Spaces / workspaces | Zen, Arc, Edge, Vivaldi, Opera | ✅ |
| Split view | Zen, Arc, Vivaldi, Edge | ✅ (two panes) · 🔜 grids of 3–4 |
| Glance / Little Arc / peek | Zen, Arc | ✅ |
| Compact mode | Zen, Arc | ✅ |
| Sleeping / discarded tabs | Edge, Vivaldi, Chrome, Arc | ✅ (Settings → General) |
| Tab search | Chrome, Edge, Arc | ✅ (address bar searches open tabs) |
| Reopen closed tab | all | ✅ Ctrl+Shift+T |
| Tab folders / groups | Zen, Arc, Chrome, Edge | 🔜 |
| Auto-archive old tabs | Arc | 🔜 |
| Tab hover previews | Edge, Vivaldi | 🔜 |
